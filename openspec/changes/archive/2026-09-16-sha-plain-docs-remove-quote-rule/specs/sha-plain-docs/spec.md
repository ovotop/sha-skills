## MODIFIED Requirements

### Requirement: 目标语言选择

技能 MUST 根据用户语境或明确指定选择目标语言（中文/英文）；中文文档 SHALL 应用中文受控写作规则（含中英文之间空格、全角标点）；英文文档 SHALL 应用精简 STE 方向性规则（短句、主动语态、一词一义）。引号风格（「」/""/''）不受约束，脚本不得将其列为违规。

#### Scenario: 中文文档

- **WHEN** 用户以中文要求撰写中文技术文档
- **THEN** 输出应用中文受控写作规则，含 40 字句长上限与标点规范

#### Scenario: 英文文档

- **WHEN** 用户要求撰写英文文档
- **THEN** 输出应用精简 STE 原则而非中文规则

#### Scenario: 引号风格不构成违规

- **WHEN** 文档正文使用 ASCII 直引号（如直接引用英文原文或代码片段）而不用「」
- **THEN** 输出不被视为违反受控写作规则，脚本不报违规

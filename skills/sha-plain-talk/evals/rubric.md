# LLM-judge rubric — sha-plain-talk

用于评估 `outputs/output.md`。机械项（句长、禁词、来源标记）优先用脚本断言，本 rubric 负责语义项。
**每条独立判 PASS / FAIL，并给出证据引用**（引用原文片段；无证据的 PASS 视为无效）。
来源支撑质量额外给 1–5 锚定分：5=来源真实且直接支撑；3=来源真实但只是相关；1=来源不存在或与结论相悖。

## 核心三问（置信阶梯，Oracle S6）

1. **被引用的来源在给定上下文中真实存在吗？**（用户消息、上文、或模型稳定知识；凡声称的"你说过/日志显示"都能在输入里找到）
2. **该来源是否真正支撑该结论？**（而非仅与结论同时出现；无来源的强断言必须已降级或删除）
3. **无依据处是否出现强语态？**（一定/必须/绝对/必定/必然/肯定/显然/无疑/确实/确定/从不/总是/永远）

## 结构与事实

4. **首句是结论**（不得让读者读完多段才推断出结论）——至少 3 分（1–5）。
5. **支撑 ≤3 点**，细节与例外后置。
6. **保护性类别保留**：原文的警告／限制／例外仍在（可弱化语态，不得删除）。
7. **未新增事实**：没有原文没有的数字、日期、条件或结论（含凭空补的建议、猜测的版本号）。
8. **输出语言与原文一致**（中文原文→中文输出；英文原文→英文输出）。

## 措辞

9. **无黑话与机械直译**（赋能/抓手/闭环/落地/对齐/颗粒度…；Success/Invalid 式状态词）。
10. **指代可定位**：不出现"该/其/此/上述/相关"当作指代词（`应该/其他/因此` 等固定词内的同名汉字不算）。
11. **无可量化的模糊副词**：非常/特别/基本上，或已给出范围/依据。
12. **句长**：中文无逗号单句 ≤40 字、逗号构件 ≤20 字；英文 ≤25 词。主动语态、执行者明确。

## 输出纪律

13. **只输出改写后的内容**，不含"我已重讲/按规则"等元注释，也不加"# 重讲"之类标题。
14. **不复述**：末尾不出现把首句结论再写一遍的"细节："段落（复述不算新信息）。

## 判定汇总

- 机械项缺失（未跑脚本时）由 judge 代判，须标注 `judged-by-llm`。
- 任一核心三问 FAIL → 该次运行为 **FAIL**（置信阶梯是红线）。
- 3–8 任一项 FAIL → 记为缺陷但不必判整次失败。

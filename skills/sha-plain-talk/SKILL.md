# sha-plain-talk —— 重讲上一条

**两种触发方式**：（1）显式调用（`/sha-plain-talk`、点名技能名）；（2）自然语言触发——用户说“你说啥”“没听懂”“没明白”“什么意思”“再说一遍”“没看懂/没看清”等针对**上一条回复**的困惑短语，自动进入重讲。**仍不进入**：用户提新问题、新请求（这是新对话不是重讲）；“重新回答一遍”“这次用英文”等重做/语言切换请求（换语言或重做内容 ≠ 没听懂）；困惑指向更早的消息而非上一条。**输出语言与原文一致**（中文回复输出中文，英文回复输出英文）。

## 工作流

取最近一条 AI 回复 → 定位结论（推不出就问用户，不编）→ 按“结论 → ≤3 支撑 → 细节后置”重排（**内容只够一句就用一句，不要为凑结构加要点**）→ 套内核表与置信阶梯 → 过自检 → 直接输出改写内容，不写元注释。

## 内核表（[通用] / [zh] / [en]）

- 结论先行[通用]：首句结论；有多个支撑点才列，≤3；细节与例外按需后置
- 保留事实[通用]：走置信阶梯；不新增原文没有的数字、日期、条件、结论
- 一词一义[通用]：不为避免重复换同义词；不直译 Success/Invalid 类状态词
- 显式主语+主动[通用]：一句一义，执行者明确（区分系统自动与人工操作）
- 避免模糊副词[通用]：删"非常/特别/基本上"，或给出可量化依据
- 明确指代[通用]：不用"该/其/此/上述/相关"，重复具体对象名称
- 引号[通用]：简体中文用弯引号“ ”/‘ ’，不用直角引号「」『』（日文/繁中风格）
- 句长[zh]：单句总长 ≤40 字（**超 40 一律违规**，带逗号也一样）；逗号构件 ≤20 字；[en]：≤25 词

## 置信阶梯（"保留事实"的红线）

- 有依据（对话/文档/模型稳定知识）→ 强语态（一定/确认），对话与文档来源写进句中
- 无依据·可定性为推测 → 弱语态（可能/据我判断），明示是推断
- 无依据·不可判断 → 删除
- 规范要求（必须/不得/禁止）是命令不是事实断言：不需要来源标记，但不得新增原文没有的要求

**警告、限制、例外是保护性类别**：无论有无依据都保留，可弱化语态，不得删除。来源标记只标新增信息：（你上一条消息）（上文已确认）（来自 logcat）。

## 输出前自检（不通过就改）

① 首句是结论、支撑 ≤3 点（只有一点就写一点）？② 每个事实型强断言（一定/绝对/确认…）都能指出来源，没来源的已加来源、降级或删除；**必须/不得 类规范要求不改来源标记**（但不得新增原文没有的要求）？③ 无黑话、无机械直译？④ 指代可定位——没把"该/其/此/上述/相关"当指代词用（`该接口`→`这个接口`，`相关信息`→`日志里的错误码`，`相关人员`→`值班负责人和测试同学`；`应该/其他/因此/极其` 等固定词里的同名汉字不算）？⑤ 中文 ≤40 字、英文 ≤25 词，主动语态？⑥ 没有复述首句的"细节/备注"尾段，没有"原文没说明…""我已重讲"这类元注释？

## 输出

首句结论；只有确实存在多个支撑点时才用 `1. 2. 3.` 列点（≤3 条，能一句说清就别列）；只有存在**新的**细节或例外时才在末尾补充，不得复述首句，不得写"原文没说明…""已完成重讲"这类元注释。

# 禁用词与黑话清单（avoid-words）

本文件是 `check_plain.py` 的**机器可读词表**，也是 `sha-plain-docs` 与 `sha-plain-talk` 共用的措辞黑名单。
`sha-plain-talk/SKILL.md` 内联其中的 **top-15 子集**（本文件标 `[T]` 的条目）；本文件是全集与母子关系的上位。

## 行格式（脚本依赖，勿改）

```
- <词> → <平实替代> [标签]
- /<正则>/ → <平实替代> [标签]
```

- 行首 `- ` 开头即一个词条；`→` 之前是**待检模式**，之后是**建议替代**。
- 待检模式默认按**字面匹配**（literal）。用 `/.../` 包裹时按**正则**匹配（脚本用 Python `re`）。
- `[标签]` 可选，纯注释：`[T]` = talk 内联的 top-15；`[pp]` = 指代词类。
- `##` 开头的行是分节标题，脚本忽略。
- `### 允许清单` 节下的条目为**豁免项**：命中位置若落在豁免词内则跳过（例如“其”在“其中”里不算违规）。

判断依据见 `rules.md`（中文受控写作）与 `rules-en.md`（英文 STE）。**替换建议是等义平实表达，不是机械同义替换**：若替换会改变原意，改写整句。
